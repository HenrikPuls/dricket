# Code of conduct

This project is for people who want to build a dependable ticketing tool. To
keep it that way:

- Be respectful. Criticise ideas and code, not people.
- Assume good faith, and say so when you are unsure what someone meant.
- No harassment, discrimination, personal attacks or doxxing.
- Keep discussion on topic and technical. Marketing spam is removed.

The maintainer may edit, hide or remove contributions, and may block people
who repeatedly break these rules. To report a problem, contact the maintainer
through the address on their GitHub profile.

If you prefer an established text, you may replace this file with the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
