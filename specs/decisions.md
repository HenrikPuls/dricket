# Decisions against

Ideas that were excluded or dropped. Do not re-propose them. Ideas that are
only postponed live under "Later" in specs/roadmap.md, with their trigger.

| Date | Idea | Why not |
|---|---|---|
| 2026-11-02 | Move ticket files between stage folders | The path must stay stable; the stage lives in the front matter |
| 2026-11-02 | Front matter fully generated by the tool | Then even a title change needs the tool; only identity is immutable and state tool-only |
| 2026-11-02 | The ticket tool pushes code branches | Mixes two repos and two permission models; the runner wrapper pushes code |
| 2026-11-02 | Heartbeat commits to keep a lease alive | Too many commits; long leases by size plus `extend` with a reason |
| 2026-11-02 | Built-in watcher or background poller | Users loop `dk inbox` themselves (`watch`, cron, timer) |
| 2026-11-02 | Shell scripts as the implementation | Not portable (quoting, Windows), fragile parsing |
